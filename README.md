## Origami Algorithm for Performing the Design Process of Cyclic Graphs

### Compile
```g++ -o origami-algorithm origami-algorithm.cc```

### Run
```./origami-algorithm```

### Input Format
First line: ```n m```

```n```: Number of nodes

```m```: Number of edges

Each of the next ```m``` lines: ```i j w```

```i``` and ```j``` are node indices.

```w``` is the edge weight between nodes ```i``` and ```j```.
